# structure-permit-checker

공작물 축조신고·개발행위허가 사전 판정기 (건축법·국토계획법·지자체 도시계획조례 기준)

## 개요

지자체, 용도지역, 공작물 종류와 공작물의 높이·수평투영면적·무게·부피를 입력하면
다음 두 가지를 자동으로 판정합니다.

1. **공작물 축조신고** 대상 여부 — 건축법 제83조 제1항, 같은 법 시행령 제118조 제1항
2. **개발행위허가** 대상 여부 — 국토계획법 제56조, 같은 법 시행령 제53조 및 각 지자체 도시계획조례

판정 결과와 함께 근거 법령 조문, 제출서류 목록, 별지 서식이 수록된 법령 링크를 출력합니다.

## 지원 지자체

포천시 · 양주시 · 성남시 · 광명시 · 동두천시 ·
인천 중구/연수구/남동구/부평구/강화군(인천광역시 도시계획 조례 공통 적용) · 제주시 · 서울특별시(참고)

[지역 기준 데이터 관리] 탭에서 조례 수치를 수정하거나 새 지자체를 추가할 수 있습니다.

## 사용법

브라우저에서 페이지를 열고 값을 입력한 뒤 [판정] 버튼을 누르면 됩니다. 설치·가입 불필요.

## 면책

본 도구는 사전 자가진단용 참고자료이며 법률자문이 아닙니다.
조례는 수시로 개정되므로, 실제 인허가 전 반드시 국가법령정보센터에서 최신 시행본을 확인하고
관할 시·군·구 허가부서(건축과·도시과)에 사전 문의하시기 바랍니다.
개발제한구역·산지·농지·문화재구역 등 중첩규제는 별도 법령의 허가가 추가로 필요합니다.
